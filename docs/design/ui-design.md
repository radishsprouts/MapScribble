# MapScribble 画面設計（ツールの帯・文字入力の画面・地図上のメモ・文言・素材）

- 作業区分: community（無料運営のサーバー向けクライアント MOD。収益化の要素は入れない）
- 担当: Dev-UI-Designer（2026-10-20）
- 元になる章: プラン `03-操作と画面.md`・`05-JourneyMap連携と描画.md`
- モックアップ: `docs/design/ui-mockup.html`（1 GUI ピクセルを 2 CSS ピクセルで表示。ブラウザで開く）

単位はすべて **GUI ピクセル**（Minecraft の GUI 倍率を掛ける前の座標）。例外は地図上の線の太さで、これは JourneyMap の `ShapeProperties.setStrokeWidth` に渡す値（画面ピクセル）で書く。

---

## 1. 目的・利用者・主要タスク

- 利用者: 無料サーバー（一般 `lis_world`・資源 `res_world`）で JourneyMap を使っているプレイヤー本人。メモは自分にだけ見える
- 主要タスク
  1. 全画面マップで手書きモードにして、区画をなぞって囲み、文字を付ける（主機能）
  2. 線を引く・文字だけを置く
  3. 描いたメモを消す・直す・元に戻す
  4. メモ全体を一時的に隠す
- 動線: 全画面マップ（JourneyMap）→ 右列の「手書き」ボタン（またはキー）→ ツールの帯が出る → 描く → 文字入力の画面 → 確定で地図へ戻る → 手書きボタンでモードを終える

見られなかったもの（事実として書く）:
- JourneyMap 6.0.x の**右列の実物の画像**は見つからなかった（公式画像は旧テーマの画像で、右列のボタンが写っていない）。右列の縦方向の範囲は、左列と同じく縦中央に並ぶと仮定し、帯の位置はどちらの仮定でも重ならない場所にした（3.1）
- MapFrontiers の全画面マップのボタン配置の画像は無かった（Modrinth のギャラリーは空）
- 同種サービスの実物（Google マイマップ等）は今回ブラウザで開いていない。描画ツールを「ツールの帯＋選択中の状態表示」で並べる形は、上の MapFrontiers と JourneyMap 自身のボタン群の作法を根拠にした

### そこから採ったこと

- 右列は JourneyMap と他のアドオンのボタンが増える場所、上部・下部・左は JourneyMap の固定のボタンと表示行。**MapScribble の帯は、そのどれにも触れない左上の「上部ツールバーと表示行の下、左列の右」に置く**
- アイコンは JourneyMap に合わせて**白い単色の線画・透過**にし、状態の色はプログラムで乗せる
- 地図上の囲みは MapFrontiers と同じ「実線＋半透明の塗り＋中央の文字」にする（利用者が知っている見え方）
- アイコンだけにしないため、帯の最下段に**選択中のツール名と操作の説明を常に文字で出す**（ツールチップだけに頼らない）

## 3. 推奨案

### 3.1 ツールの帯（手書きモード中だけ表示）

**置き場所: 画面の左上、原点 (x=28, y=44)、大きさ 208×57。** 画面の大きさ・GUI 倍率にかかわらず同じ位置に固定する。

根拠:
- Minecraft は GUI 座標が 320×240 未満にならないよう倍率を選ぶ。最小の 320×240 で、JourneyMap の各要素は次の範囲にある（実測からの見込み）。帯 (28..236, 44..101) はどれとも重ならない
  - ロゴ: x 0..22, y 0..22 / 上部ツールバー: 中央、y 0..22 / 表示行: y 約24..34
  - 左列: x 0..24、縦中央（240 の時 y 約78..162）→ 帯は x 28 から
  - 右列: x 296..320 → 帯の右端 236
  - 下部ツールバーと表示行: y 206..240 / キー一覧: 右下
- `FULLSCREEN_RENDER_EVENT` は**ボタンより先に**呼ばれる（05章）。重なると JourneyMap のボタンが帯の上に描かれてしまうので、重ならないことが必須
- 縦に並べる案は、最小の画面で高さが足りない（全要素で 200 を超える）ため落とした。色・太さを押して開く小窓にする案は、色を変えるたびに1手増え、小窓が左列に重なるため落とした

一時のお知らせ: 「メモを消しました（Ctrl+Z で戻せます）」「元に戻しました」「やり直しました」「囲みが小さすぎるため取り消しました」「線が短すぎるため取り消しました」「ここにはメモがありません」「メモを表示してから選んでください」「描いたメモを取り消しました」

**状態ごとの帯の振る舞い**

- 読み込み中・地図の準備中・読み込み失敗: ツール・色・太さは押せる（選んでおける）が、地図への描画・消しゴム・編集のクリックは何もしない（地図の移動も止めない＝ドラッグを取り消さない）。元に戻す・やり直すは無効
- メモを隠している時: 囲み・線・文字は描ける。**新しいメモを確定したら自動で表示に戻す**（描いたのに見えない、を防ぐ）。消しゴム・編集のクリックは「メモを表示してから選んでください」を出して何もしない
- 権限なし: この MOD はクライアントだけで自分のメモを扱うため、権限で操作を分ける場面は無い（サーバーの権限チェックも無い）

**地図の上での手応え**

- 描いている最中の線: 選択中の色、太さは `max(1, round(地図上の太さ ÷ GUI倍率))` GUI ピクセル、不透明度 100%
- 囲みを描いている最中は、今の指の位置から始点へ、同じ色・不透明度 50%・太さ 1 の直線を出す（離すと閉じることを見せる）
- 消しゴム・編集でメモの上にカーソルがある時: カーソルの右下にツールチップで「クリックで消す：<メモの文字の1行目>」「クリックで編集：<同>」。文字が無い時は「文字なしの囲み」「文字なしの線」
- カーソルが帯の上にある時は、地図側のホバー表示を出さない

**選択ボタンの中身**（バニラの「ラベル: 値」の表示。押すたびに次の値、Shift で前の値）

| ボタン | 値（既定は太字） | 地図での値 |
|---|---|---|
| 塗り（囲みだけ） | なし / うすい / **ふつう** / こい | 不透明度 0 / 0.15 / 0.30 / 0.50 |
| 文字の大きさ | 小 / **中** / 大 | `TextProperties` の大きさ 1.0 / 1.5 / 2.0 |
| ミニマップ | **表示** / 非表示 | `setActiveUIs` に Minimap を含める / 含めない |

色・太さ・塗り・文字の大きさ・ミニマップの値は、最後に使った値を覚えて次の新しいメモの既定にする（ゲームを再起動しても）。太さは帯で決め、この画面には出さない。

**見出し**: 新規「囲みのメモ」「線のメモ」「文字のメモ」、編集「囲みのメモを編集」「線のメモを編集」「文字のメモを編集」

**ボタン**
- 確定: メモを追加（新規）または変更（編集）して閉じる。取り消しの履歴に1件積む
- キャンセル: 新規なら**描いた形ごと取り消して**閉じ、帯に「描いたメモを取り消しました」。編集なら何も変えずに閉じる
- 削除（編集だけ）: 文字色 `#FF5555`。確認は出さず消して閉じ、帯に「メモを消しました（Ctrl+Z で戻せます）」。確認の代わりに元に戻すで戻せる
- 文字のメモで欄が空（空白だけを含む）の間、確定は無効（バニラの無効表示）。囲み・線は空でも確定できる（文字なしのメモ）

**キー操作**
- Esc = キャンセル、Ctrl+Enter = 確定（文字のメモで空欄なら何もしない）、Enter = 改行
- Tab / Shift+Tab のフォーカス順: 文字の欄 → 色の見本（10個で1つの止まり場所。←→で色を選ぶ）→ 塗り → 文字の大きさ → ミニマップ → 削除 → 確定 → キャンセル
- 開いた時のフォーカス: 文字の欄（すぐ打てる）。フォーカス中のバニラのボタンは白枠（バニラ既定）

| 表示先 | 全画面＋ミニマップ（ミニマップ「非表示」のメモは全画面だけ）。Webmap には出さない |

`strokeWidth` の単位が実機で GUI ピクセルだった場合は、値を 1.0 / 2.0 / 3.5 に読み替える（05章の「確かめること」と同じ時に確かめ、どちらだったかを報告に書く）。

### 3.4 色の一覧（10色）

地図の地形（草の緑・海の青・砂・雪の白・洞窟の黒）の上で見分けやすく、文字の背景（黒 80%）の上で最悪の場合（下が雪の白）でも 4.5:1 を超えるように明るさを選んだ。

| 順 | 名前 | キー | RGB | 文字の背景（黒80%を白の上に重ねた `#333333`）との比 |
|---|---|---|---|---|
| 1 | 赤 | red | `#FF6E61` | 4.6:1 |
| 2 | 橙 | orange | `#FF9500` | 5.7:1 |
| 3 | 黄 | yellow | `#FFE600` | 9.9:1 |
| 4 | 黄緑 | lime | `#7CFC00` | 9.5:1 |
| 5 | 水色 | aqua | `#32D2FF` | 7.1:1 |
| 6 | 青 | blue | `#5C9DFF` | 4.6:1 |
| 7 | 紫 | purple | `#C584FF` | 4.9:1 |
| 8 | 桃 | pink | `#FF6FD0` | 5.1:1 |
| 9 | 白 | white | `#FFFFFF` | 12.6:1 |
| 10 | 黒 | black | `#1A1A1A` | （白80%の背景を黒の上に重ねた `#CCCCCC` と）10.8:1 |

**手書きモードの切替**

3. 操作設定に「手書きモードの切替」（分類 MapScribble、既定は未割り当て）があり、割り当てたキーでも 2 と同じに切り替わる

**ツールの帯（配置）**
4. (a)〜(e) のすべてで、帯の左上が GUI 座標 (28,44)、大きさ 208×57 で表示される
5. (a)〜(e) のすべてで、帯が JourneyMap のロゴ・上部ツールバー・表示行・左列・右列・下部ツールバー・キー一覧のどれとも1ピクセルも重ならない（Keys オン/オフの両方）
6. 帯の中の各要素が 3.1 の表の位置・大きさで並ぶ（ツール5・区切り・戻す/やり直す・区切り・表示の切替が1段目、太さ3・区切り・色10が2段目、説明の行が3段目）
7. 帯の背景が `#101418` 80%、縁が 1px の白 20% で、後ろの地図が透けて見える

**ツールの帯（状態）**
8. 手書きモードに入った直後、前回選んだツール・色・太さが選択中で表示される（初回は 囲み・赤・中）
9. 選択中のツールボタンは青い面＋白い縁で、説明の行にそのツールの説明（3.1 の文言）が出る。別のツールを押すと選択と説明が即座に切り替わる
10. 太さのボタンの横棒は 1 / 2 / 3 ピクセルで、選択中の色で塗られている。色を変えると横棒の色も変わる
11. 色の見本を押すと、その見本に白い 1px の外枠が付き、以後描くメモがその色になる
12. 取り消せる操作が無い時、元に戻すボタンは無効の表示（アイコン 35%）で、押しても何も起きず、ツールチップに「元に戻す操作はありません」。やり直すも同様
13. 各ボタンにホバーすると 3.1 のツールチップ（1行目の名前と2行目の説明）が出る
14. 表示の切替を押すとメモが地図から消え、アイコンが斜線の目になり、説明の行が黄色の「メモを隠しています（目のボタンで表示）」になる。もう一度押すと戻る
15. メモを隠している間に囲みを描いて確定すると、メモの表示が自動で戻る
16. メモを隠している間に消しゴム・編集で地図をクリックすると「メモを表示してから選んでください」が出て、何も消えない・開かない
17. そのディメンションにメモが0件でツールが囲みの時、説明の行が「まだメモがありません。ドラッグして範囲を囲んでみましょう」になる
18. 保存先が決まる前（地図の準備中）に手書きモードにすると、説明の行が黄色の「この地図にはまだ描けません（地図の準備中）」になり、ドラッグで地図が通常どおり動く（メモは描かれない）
19. 読み込み中は説明の行が灰色の「メモを読み込んでいます…」になり、描画・消しゴム・編集のクリックは何もしない
20. 知らない形式のメモのファイルがあるワールドで手書きモードにすると、説明の行が赤系の「このワールドのメモを読み込めませんでした（ファイルは変更していません）」になり、そのファイルの中身が変わらない
21. 保存に失敗した時、説明の行が赤系の「メモを保存できませんでした。ログを確認してください」になり、次に保存が成功するまで残る
22. 一時のお知らせ（消した・戻した・やり直した・小さすぎ・短すぎ・ここにはメモが無い・取り消した）は説明の行に約4秒出て、その後ツールの説明に戻る
23. 帯の上でのクリック・ドラッグは地図に渡らない（地図が動かない、メモが描かれない）

**描く・消す・直す**
24. 囲みでドラッグしている最中、選択中の色の線が指の跡に沿って描かれ、指の位置から始点へ半透明の細い線が出る。離すと閉じた囲みになり、文字入力の画面が開く
25. 短いクリックや面積がほぼ0の囲みは作られず、「囲みが小さすぎるため取り消しました」が出る
26. 線でドラッグして離すと文字入力の画面（見出し「線のメモ」）が開く。点が2つ未満なら「線が短すぎるため取り消しました」
27. 文字ツールで地図をクリックすると文字入力の画面（見出し「文字のメモ」）が開く
28. 消しゴムでメモの上にカーソルを置くと「クリックで消す：<文字の1行目>」（文字なしなら「文字なしの囲み」等）が出て、クリックするとそのメモが消え「メモを消しました（Ctrl+Z で戻せます）」が出る。メモの無い所をクリックすると「ここにはメモがありません」
29. 編集でメモをクリックすると、そのメモの値が入った編集の画面（見出し「〇〇のメモを編集」、削除ボタンあり）が開く
30. Ctrl+Z で直前の追加・変更・削除が戻り「元に戻しました」、Ctrl+Y でやり直され「やり直しました」。帯のボタンでも同じ

**文字入力・編集の画面**
31. (a)〜(e) のすべてで、パネルが幅 240 で左右中央に表示され、上下が画面からはみ出さない
32. 画面の高さが 260 未満（(a)(b)）では文字の欄が3行、260 以上（(c)(d)(e)）では5行の高さ
33. 背後に全画面マップと描いた形が暗く（黒 50%）見える
34. 囲みの画面に、文字の欄・「色：<名前>」・色10個・「塗り: ふつう」「文字の大きさ: 中」「ミニマップ: 表示」・確定・キャンセルがある。削除は無い
35. 線・文字の画面には「塗り」が無く、「文字の大きさ」「ミニマップ」が1段に並ぶ
36. 編集の画面では左下に赤い文字の「削除」があり、押すとメモが消えて地図へ戻り「メモを消しました（Ctrl+Z で戻せます）」が出る
37. 開いた直後に文字の欄にフォーカスがあり、そのまま文字を打てる。Enter で改行される
38. Ctrl+Enter で確定され、地図へ戻ってメモが表示される
39. Esc（またはキャンセル）で、新規なら描いた形が残らず「描いたメモを取り消しました」が出る。編集ならメモが変わらない
40. 文字の欄の下に「Ctrl+Enter で確定 / Esc で取り消し」と「<文字数>/200」が出て、200 文字を超えて入力できない
41. 文字のメモで欄が空の間、確定ボタンが無効で、欄の下に赤系の「文字のメモには文字が必要です」が出る。Ctrl+Enter でも閉じない
42. 囲み・線は欄が空のまま確定でき、文字なしのメモになる
43. 色の見本を押す（またはフォーカスして←→）と選択の白枠が移り、ラベルが「色：<名前>」に変わる
44. 選択ボタンを押すたびに値が順に変わる（塗り: なし→うすい→ふつう→こい→なし、文字の大きさ: 小→中→大→小、ミニマップ: 表示⇔非表示）
45. Tab で、文字の欄 → 色 → 塗り → 文字の大きさ → ミニマップ → 削除 → 確定 → キャンセル の順にフォーカスが移り、フォーカス中の部品に枠が見える
46. 確定・キャンセル・削除のどれでも、閉じた後は全画面マップ（手書きモードのまま）に戻る
47. 次に新しいメモを作る時、前回選んだ色・塗り・文字の大きさ・ミニマップが既定になっている（ゲームの再起動後も）

**地図上のメモ**
48. 囲みは、メモの色の実線（中＝太さ 4）と同じ色の半透明の塗り（ふつう＝30%）で描かれ、中央に文字が出る
49. 文字はメモの色で、黒 80% の背景と影が付く。黒のメモだけは黒い文字に白 80% の背景で、影が無い
50. 塗りを「なし」にした囲みは輪郭だけ、「こい」は塗りが 50% で見える
51. 線は閉じずに描いた跡のとおりに出て、塗りが無い。文字は線の中ほどに出る
52. 文字の大きさ 小・中・大で、地図上の文字の大きさが3段階に変わる
53. ミニマップ「表示」のメモはミニマップにも出て、「非表示」のメモは全画面マップにだけ出る
54. 雪原（白）・海・草地・砂漠の上のどこでも、10色すべての文字が読める（背景の矩形が文字の後ろにある）

## 9. アクセシビリティ要件

- 選択・状態を色だけで示さない: ツールは白縁＋説明の行の文字、色は白枠＋「色：<名前>」、表示の切替は目の絵柄＋説明の行、失敗は文字で内容を書く
- 文字のコントラストは 4.5:1 以上、部品の縁・アイコンは 3:1 以上（4 の計算値）
- 文字入力の画面はキーボードだけで完結する（Tab・←→・Enter・Ctrl+Enter・Esc）
- 帯の操作はマウスで行う（JourneyMap の全画面マップ自体がマウス操作のため）。取り消し・やり直し・モードの切替はキーでもできる
- 押せる領域: 帯のボタン 20×20、太さ 20×14、色 12×12（GUI 倍率2で 24×24 画面ピクセル）。文字入力の画面の色は 16×16
- ドラッグでしかできない操作は「囲み」「線」を描くことだけで、これは描画そのもの。消す・直す・色や太さの変更はクリックでできる

## 10. 自己評価（モックアップ `ui-mockup.html` をブラウザで開いて実施）

モックアップは GUI 320×240（最小）、427×300、960×540 の3つの大きさで、帯と文字入力の画面を並べた。ウェブの画面幅（1440px/375px）の代わりに、Minecraft の GUI 座標の最小と広い場合で見た。

1. 一目で分かるか: 最小の画面で「左上の帯でツールを選び、地図に描く画面」と言える。選択中のツールは青い面と説明の行で分かる
2. 認知的ウォークスルー（囲んで文字を付ける）
   - 手書きを始める: 右列の鉛筆ボタン。ホバーで「手書きモードにする」と出るので結び付く
   - 囲みを選ぶ: 初回は既に選ばれていて、説明の行が「ドラッグして範囲を囲む」と言う
   - 描く: 指から始点への半透明の線で、離すと閉じると分かる
   - 文字を付ける: 画面が開き、すぐ打てる。確定のキーが欄の下に書いてある
   - 結果: 地図に囲みと文字が出る
3. 10ヒューリスティクスで見つけた点
   - 中: 帯のボタンはアイコンだけで、名前はツールチップと説明の行（選択中のものだけ）に出る。ボタンの下に名前を常に並べると最小の画面で幅が 320 を超えるため、選択中のツール名を常に出すことで補った
   - 中→解消: 新規のキャンセルが「形ごと取り消す」ことが分かりにくい → 欄の下に「Esc で取り消し」、閉じた後に「描いたメモを取り消しました」を出すことにした
   - 中→解消: 隠している間に描いたメモが見えない → 確定で自動的に表示へ戻すことにした
   - 低: 囲みの画面の「ミニマップ」ボタンが2段目に1つだけで右が空く。線・文字と並びが変わらないよう、そのままにした
   - 高: なし
4. コントラスト: 4 に計算値を書いた（WCAG の相対輝度の式。下が雪の白の最悪の場合で計算）

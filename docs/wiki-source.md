## どんな機能か

JourneyMap・Xaero's World Map・FTB Chunks の全画面マップに、手書きでメモ（囲み・線・文字）を描ける、自分だけのクライアント MOD。Fabric / Forge / NeoForge 対応で、Minecraft 1.20.1 / 1.20.6 / 1.21.1 / 1.21.4 / 1.21.11 / 26.1.2 / 26.2 / 26.3 の jar がある（版ごとに jar が別）。メモは自分のゲームの中だけにあり、サーバーには何も送らず、ほかのプレイヤーには見えない。サーバー側に入れるものは無い。

## プレイヤーの使い方

1. 地図 MOD の全画面マップを開く
2. 鉛筆のボタンを押す（ホバーで「手書きモードにする」）。もう一度押すと「手書きモードを終える」になり、通常の地図の操作に戻る
3. 手書きモードの間だけ画面にツールの帯が出る。道具（囲み=1・線=2・文字=3・消しゴム=4・編集=5。数字キーで切り替え）を選び、地図をドラッグまたはクリックして描く
4. 囲み・線・文字を描き終えると文字入力の画面が開く。Ctrl+Enter か「確定」で保存、Esc か「キャンセル」で取り消す
5. 元に戻す=Ctrl+Z、やり直す=Ctrl+Y または Ctrl+Shift+Z（帯のボタンでも可）

### 鉛筆のボタンの位置と動かし方

| 地図 MOD | 鉛筆のボタンの位置 | 動かせるか |
|---|---|---|
| JourneyMap（公式プラグインで連携） | 全画面マップの右の列（JourneyMap のテーマのボタン） | 動かせない（位置は JourneyMap が決める） |
| JourneyMap（公式プラグインが動かない時。1.20.6 向け jar など） | 画面の右上。JourneyMap の閉じるボタンの左隣 | 動かせる |
| Xaero's World Map / FTB Chunks | 画面の右上 | 動かせる |

動かせるボタン（画面の右上に出るもの。Xaero's World Map の方角表示などに重なった時に動かす）:

- 左ボタンを押したまま動かして離す: カーソルに付いてきて、離した所に置かれる。手書きモードは変わらない。押した点から 4 画面ピクセル以上動かすとドラッグになる
- 動かさずに左ボタンを離す: 手書きモードが切り替わる（押した時ではなく離した時）
- Shift を押しながら左クリック（動かさず離す）: ボタンを掴む。次の左クリックでその場所に置かれる
- 右クリック: 元の位置へ戻る
- 動かしている間の Esc（掴んでいる間は右クリックも）: 動かす前の位置へ戻して取り消す。地図の画面は閉じない
- ボタンは画面の外へ出ない。ツールの帯と重なった時は帯が手前で、重なった部分のクリックは帯が受ける
- 位置は地図 MOD ごとに別々に、近い画面の端からの距離で覚え、ゲームを再起動しても残る。ツールチップの 3 行目に動かし方、動かしてある時の 4 行目に戻し方が出る

### ツールの帯

- 手書きモードの間だけ出る。ボタンの無い余白を左ドラッグすると画面内の好きな位置へ動かせ、位置は覚えている
- 上段: 道具5つ／元に戻す・やり直す／文字だけの表示・非表示／メモ全体の表示・非表示（目のボタン）／手書きモードを終える（右端の縦長のボタン）
- 下段: 線の太さ3段（細・中・太）／文字の大きさ3段（小・中・大）／色10色（赤・橙・黄・黄緑・水色・青・紫・桃・白・黒）

### 表示の切替・ミニマップ

- 文字だけの表示・非表示: 囲み・線・文字メモの文字をすべて隠す（輪郭や線は残る）。全画面マップとミニマップの両方に効く
- メモ全体の表示・非表示: 自分のメモを地図に出す・隠す。隠している間も描ける（描くと表示に戻る）
- ミニマップ: メモごとに文字入力の画面の「ミニマップ」で表示・非表示を選べる（既定は表示）。JourneyMap と Xaero's Minimap のミニマップに出る。FTB Chunks のミニマップには出ない。1.20.6 向けの jar は JourneyMap のミニマップに出ない

## 数値

| 項目 | 設定のキー | 既定値 | 本番の値(確かめた日・サーバー) |
|---|---|---|---|
| 文字メモの長さ | （設定なし） | 1000 文字まで | サーバーに入れる物ではないため該当なし |
| 元に戻す履歴 | （設定なし） | 100 件まで。ディメンションや接続先が切り替わると破棄 | 同上 |
| 保存の遅延 | （設定なし） | 変更から約1秒後にまとめて書き出す | 同上 |
| ドラッグの判定 | （設定なし） | 押した点から 4 画面ピクセル | 同上 |
| UI の設定の保存先 | `config/mapscribble-ui.json` | 道具・色・太さ・塗り・文字の大きさ・ミニマップ・帯の位置・動かした鉛筆のボタンの位置（`toggleButtons`） | 同上 |

0.1.0 のメモの引き継ぎ: 0.1.0 が JourneyMap のワールドごとのフォルダ（`<.minecraft>/journeymap/data/{mp,sp}/<フォルダ>/addon-data/mapscribble/`）に保存したメモは、その保存先を初めて開いた時に、同じ名前のファイルが無ければコピーして引き継ぐ（元のファイルは残る）。0.4.0 で、これまで見落としていた場所を見るように直した。同じアドレスに 0.1.0 のフォルダが2つ以上ある時（プロキシ配下で JourneyMap が分けていた時）は、直下へは入れず、フォルダごとにメモ帳として取り込み、説明の行に「0.1.0 のメモをメモ帳として取り込みました」と出る。

メモの保存先: シングルプレイは `<.minecraft>/mapscribble/saves/<ワールドフォルダ名>/`、マルチプレイは `<.minecraft>/mapscribble/servers/<ホスト_ポート>/`。ディメンションごとに別のファイル。接続に使ったアドレスで分かれる（プロキシ配下で別のサーバーへ移っても、接続先のアドレスが同じなら同じフォルダ）。

## プレイヤーに出るメッセージ(原文のまま)

| 場面 | メッセージ（ja_jp） |
|---|---|
| 鉛筆のボタン（オフ）のツールチップ | 手書きモードにする / ツールの帯を出して、地図に手書きできます / ドラッグまたは Shift+クリックで移動 |
| 鉛筆のボタン（オン）のツールチップ | 手書きモードを終える / ツールの帯を閉じ、地図の操作に戻ります / ドラッグまたは Shift+クリックで移動 |
| 動かしてある時の追加の1行 | 右クリックで元の位置へ戻す |
| 掴んでいる間 | クリックで置く / 右クリックか Esc で取り消し |
| メモが 0 件 | まだメモがありません。ドラッグで囲もう |
| 読み込み中 | メモを読み込んでいます… |
| 地図の準備中 | まだ描けません（地図の準備中） |
| 読み込み失敗 | メモを読み込めません（ファイルはそのまま） |
| 保存失敗 | メモを保存できません（ログを確認） |
| メモを隠している | メモを隠しています（目のボタンで表示） |
| 消した時 | メモを消しました（Ctrl+Z で戻せます） |
| 小さすぎる囲み・短すぎる線 | 囲みが小さすぎるため取り消しました / 線が短すぎるため取り消しました |
| 文字のメモが空 | 文字のメモには文字が必要です |

表示の文言は10言語（日本語・英語・ドイツ語・スペイン語・フランス語・韓国語・ポルトガル語（ブラジル）・ロシア語・中国語（簡体字・繁体字））。鉛筆のボタンの移動に関する3行は、日本語と英語を先に入れ、ほかの8言語は別の担当が追加する。

## 権限と、使えるサーバー

クライアントだけに入れる MOD で、サーバー側の権限・導入・設定は無い。どのサーバー（一般・資源を含む）でも、プレイヤーが自分のクライアントに入れれば使える。サーバーに入っているかどうかを本番で確かめる対象ではない。
